## Scope

Greenfield + the deferred subsystems that everything else has been parking here:

1. **New `canvas/vfx/` subsystem** (~21 files) — no v13 analog, no current consumers. Intentionally last. _Per the [scope-priority decision](migration-v14.md#scope-priority), this is **deprioritized** — do only if explicitly requested._
2. **`data/region-behaviors/`** (~4 files) — region behavior data models.
3. **The v14 Scene Levels subsystem** — the big one (see inherited deferral below). New `Level` document + `BaseLevel`, `SceneLevelsSetField`, `LevelData`/`LevelTexture` typedefs, the Scene rework, and the `levels`/`level` fields scattered across Scene/Token/ambient-light/ambient-sound/drawing/note/region/tile/wall. Also the missing `client/data/polygon-tree.d.mts` (`PolygonTree`).
4. **The MeasuredTemplate → client deprecation** (see inherited deferral).
5. **The 4 deferred `client/documents` Tier-B giants** — active-effect, region, scene, token (see inherited deferral). Author each one's prerequisite, then its member-diff, in one session.
6. **The client-data shapes barrel re-export** (the shadow — see inherited deferral). Rides with the region giant + Scene Levels.
7. Remaining missing files not absorbed by earlier phases.

## Sequencing note

Scene Levels gates 3 of the 4 giants (scene/region/token) — author the `Level` document + `common/data/_module` `operators` re-export **first**, then the giants become member-diffs against a real subsystem instead of stubs. active-effect is independent (its own registry/config/duration prerequisites).
